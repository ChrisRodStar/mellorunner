# MelloRunner branding

The running golden dog was approved by Christopher and generated using the built-in image-generation tool, with ZipMello's mascot as the edit reference. `logo.png` preserves the generated transparent image. Light and dark banners adapt ZipMello's existing SVG layout and embed this logo so GitHub does not need an external image request.

Rebuild banners with `python3 Tools/generate-banners.py`. Editable SVG layouts are in `assets/templates`.

Generation prompt: Preserve the friendly golden retriever, golden/cream palette, floppy ears, dark rounded outlines, black oval eyes and simple nose. Show the full dog running right in a joyful airborne stride, with head turned slightly toward the viewer, front paws reaching forward, rear paws trailing and tail lifted. Use a transparent background, generous margins, no accessories, text or scenery.
